# Sistema de Controle de Estoque com Machine learn para previsão de demanda e redução do desperdício 

> **Nome provisório:** Sistema de Controle de Estoque com Inteligência Artificial para Pequenos Negócios

## 📌 Sobre o projeto

Este projeto consiste no desenvolvimento de um sistema de controle de estoque voltado principalmente para pequenos negócios e usuários que possuem pouco conhecimento sobre gestão de estoque.

A proposta é disponibilizar uma ferramenta simples e acessível para auxiliar no controle dos produtos, geração de relatórios e acompanhamento das informações relacionadas ao estoque.

O sistema também contará com recursos de **Inteligência Artificial (IA)**, buscando facilitar a utilização da ferramenta e auxiliar o usuário na interpretação dos dados e na tomada de decisões.

> 🚧 **Status do projeto:** Em desenvolvimento.
>
> Este README será atualizado conforme novas funcionalidades e informações forem adicionadas ao projeto.

## 🎯 Objetivo

Desenvolver uma ferramenta de controle de estoque que facilite o gerenciamento de produtos para pequenos negócios, utilizando relatórios e recursos de Inteligência Artificial para tornar o sistema mais simples, acessível e útil para usuários com diferentes níveis de conhecimento em gestão de estoque.
