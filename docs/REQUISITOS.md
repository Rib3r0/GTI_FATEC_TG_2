# Requisitos

## Requisitos Funcionais
| ID       | Requisito                  | Descrição                                                                                                                 |
| -------- | -------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| **RF01** | Cadastro de produtos       | O sistema deve permitir cadastrar, editar e excluir produtos do estoque.                                                  |
| **RF02** | Informações dos produtos   | O sistema deve registrar nome, categoria, quantidade, unidade de medida, validade e estoque mínimo.                       |
| **RF03** | Movimentação de estoque    | O sistema deve registrar entradas e saídas de produtos do estoque.                                                        |
| **RF04** | Atualização automática     | O sistema deve atualizar automaticamente a quantidade disponível após cada entrada ou saída.                              |
| **RF05** | Consulta de estoque        | O sistema deve permitir consultar o estoque atual dos produtos.                                                           |
| **RF06** | Alertas de estoque mínimo  | O sistema deve emitir alertas quando a quantidade de um produto estiver abaixo do estoque mínimo.                         |
| **RF07** | Registro de desperdícios   | O sistema deve permitir registrar perdas e desperdícios de alimentos.                                                     |
| **RF08** | Histórico de movimentações | O sistema deve registrar o histórico de movimentações do estoque.                                                         |
| **RF09** | Histórico de vendas        | O sistema deve coletar dados históricos de vendas para utilização na previsão de demanda.                                 |
| **RF10** | Análise com IA/ML          | O sistema deve utilizar IA/algoritmos de Machine Learning para analisar o histórico de vendas e prever a demanda futura.  |
| **RF11** | Previsão de demanda        | O sistema deve apresentar uma previsão de demanda para determinados períodos, como dias ou semanas futuras.               |
| **RF12** | Sugestão de compras        | O sistema deve sugerir a quantidade de produtos que deve ser comprada com base na previsão de demanda e no estoque atual. |
| **RF13** | Fatores de previsão        | O sistema deve considerar fatores como sazonalidade, dia da semana e histórico de vendas na previsão de demanda.          |
| **RF14** | Relatórios                 | O sistema deve permitir visualizar relatórios sobre estoque, vendas, desperdícios e previsões de demanda.                 |
| **RF15** | Usuários e permissões      | O sistema deve permitir cadastrar usuários e definir diferentes níveis de acesso.                                         |
